# NEWS

产出一份可追溯、不过度解读的 AI 资讯简报，并同步更新仓库根目录的静态网页。

## 工作要求

1. 以当前日期为截止时间，优先收集最近 7 天的重要信息；数量不足时扩展到最近 30 天。
2. 每期只保留 5 至 8 条，优先级依次为：重大模型或产品发布、研究突破、安全事件、政策与产业基础设施。
3. 每条至少找到一个第一手来源，并用第二个可信渠道核对日期、主体和核心事实。
4. 第一手来源包括公司官网、监管机构、大学或研究机构官网、论文原文与正式技术文档。社交媒体、转载聚合页和匿名爆料不能单独作为依据。
5. 若只有企业单方声明，明确写成“该公司表示”，不得将性能排名、市场领先等宣传表述改写为既定事实。
6. 两个来源存在冲突时，不收录或明确列出分歧；不得自行补全缺失数字、日期或因果关系。
7. 摘要必须包含：时间、背景、内容、来源渠道、核验说明。
8. 使用简体中文，短句优先；保留产品和机构的官方名称。

## 页面更新

- 更新仓库根目录 `index.html` 中的新闻卡片、统计数字和“最后核验”日期。
- 保持高级黑白编辑风格、响应式布局、键盘可访问性和来源链接可点击。
- 新闻按日期从新到旧排列；每条使用稳定的两位编号。
- 不引入需要密钥的前端接口，不把 API Key、Cookie 或访问令牌写入仓库。
- 发布前检查所有外链、移动端布局和 HTML 语义结构。
